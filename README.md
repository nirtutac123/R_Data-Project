R project which incudes following contents:
Data Import and Data Wrangling (Reading different types of data files into R; Data cleaning andmanipulation using dplyr; Handling missing data)
Exploratory Data Analysis (EDA) (Descriptive statistics and data visualization; Creating basic plots (scatter plots, bar plots, histograms)
Statistical Tests with R (T-tests, ANOVA, and correlation; Understanding and interpreting outputs)
Regression Analysis with R (Linear and Logistic Regression with R; Understanding and interpreting Outputs) ARIMA Time Series Forecasting (ARIMA modeling and forecasting and interpreting outputs)
Data Interpretation and Reporting (Interpreting results from statistical analyses; Communicating findings effectively; Creating reproducible reports using R Markdown)
